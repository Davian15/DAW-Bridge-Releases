# RELAY

Downloads for RELAY by Kinetic DSP: play your DAW's master bus into calls,
and stream it to listeners by session name. Called DAW Bridge up to 0.6.

Get the latest version from [Releases](https://github.com/Davian15/RELAY-Releases/releases/latest):

- **RELAY-Setup-&lt;version&gt;.exe**: installs the app and, optionally, the
  VST3 plugin. Installed apps update themselves from here.
- **RELAY-Portable-&lt;version&gt;.exe**: the app on its own, for listeners.

Listeners without the app can join in the browser at
[listen.kineticdsp.com](https://listen.kineticdsp.com).

This repository only holds releases; the source code is not public.
