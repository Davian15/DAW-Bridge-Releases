# DAW Bridge

Downloads for DAW Bridge: play your DAW's master bus into calls, and stream
it to listeners by session name.

Get the latest version from [Releases](https://github.com/Davian15/DAW-Bridge-Releases/releases/latest):

- **DAW-Bridge-Setup-&lt;version&gt;.exe**: installs the app and, optionally, the
  VST3 plugin. Installed apps update themselves from here.
- **DAW-Bridge-Portable-&lt;version&gt;.exe**: the app on its own, for listeners.

This repository only holds releases; the source code is not public.
